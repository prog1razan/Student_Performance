# Student Performance Analysis Using Pandas

A beginner-friendly Python project that explores and analyzes student performance data using **Pandas**.

## 📌 Overview

This project uses a small student performance dataset containing academic scores, attendance rates, and study hours. The notebook demonstrates essential **Pandas and DataFrame operations** through practical exercises.

The goal is to practice data manipulation, filtering, basic statistics, and grouping using Python.

## 📊 Dataset

The dataset contains information about 8 students, including:

* Student name
* Class
* Math score
* English score
* Science score
* Attendance rate
* Study hours

Additional columns are created during the analysis, including:

* `average_score` — the average of Math, English, and Science scores.
* `status` — classified as **Pass** or **Fail** based on an average score of 70 or higher.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook / Google Colab

## 🔍 Topics Covered

The notebook demonstrates:

* Creating a Pandas DataFrame
* Exploring rows and columns
* Checking DataFrame shape and data types
* Selecting columns
* Filtering rows using conditions
* Creating new columns
* Calculating average scores
* Classifying students as Pass/Fail
* Sorting data
* Using `loc` and `iloc`
* Basic statistical operations
* Grouping data with `groupby`
